# Third-party dataset provenance

Original data file: `data/StudentPerformanceFactors.csv`, supplied as project input.

Matching public source: *Student Performance Factors*, Lai Nguyen, Kaggle:
https://www.kaggle.com/datasets/lainguyn123/student-performance-factors

Published third-party research reports that this dataset is **synthetic** and distributed with **CC0** terms:
https://www.mdpi.com/2078-2489/16/9/763

Before making your GitHub repository public, **confirm current licensing on the original Kaggle dataset page**. Its terms may change or may differ from reports. The project's code and generated material are distinct from the third-party source file. If licensing cannot be confirmed, remove `data/StudentPerformanceFactors.csv` from the public repository and instead provide instructions for users to download it themselves. The `powerbi/student_performance_powerbi.csv` file also contains derived individual-level source records, so treat it as redistributed data as well.
